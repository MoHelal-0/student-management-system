🎓 Student Management System

A simple Student Management System built with Python and SQLite to manage student records through a command-line interface.

📌 About the Project

This project provides a simple way to organize and manage student information using a SQLite database. It allows users to perform basic database operations through an interactive menu.

It was developed as a practical project to apply Python programming and SQL database concepts.

✨ Features

- View Students: Display student records stored in the database.
- Add Students: Add new student information.
- Update Students: Modify existing student records.
- Delete Students: Remove student records.
- Database Storage: Store student information using SQLite.
- Command-Line Interface: Interact with the system through a simple text-based menu.

🗂️ Student Information

The database is designed to store information such as:

- Student ID
- Name
- Classes
- Age
- Enrollment Date
- Parent Contact Information
- Student Status

🛠️ Technologies Used

- Python — Application logic
- SQLite — Database management
- sqlite3 — Python's built-in SQLite database interface
